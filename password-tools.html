Secure account guides

Configuring 2FA
  1. Open the account’s official website or app and go to its security settings.
  2. Choose an authenticator app or a hardware security key when available; SMS is better than no second factor but may be less resistant to interception.
  3. Follow the setup steps and verify the second factor before signing out.
  4. Store recovery codes in a secure place separate from the account password. Never share them or approve unexpected login prompts.
  5. Review trusted devices and recovery options periodically.
Using a Password Manager
  1. Choose a reputable password manager and protect it with a strong, unique master passphrase.
  2. Enable multi-factor authentication and set up account recovery safely.
  3. Generate a unique password for each account and save it directly in the manager.
  4. Use autofill only on the correct, verified website; do not approve unexpected prompts.
  5. Keep recovery material secure and review the manager’s security guidance and device sessions.
